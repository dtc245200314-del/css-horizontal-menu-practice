# Responsive Grid: CSS sang SCSS

Nguồn https://github.com/codegym-vn/responsive-grid, file responsive_grid.htm. Giữ nguyên cấu trúc và giá trị, đưa toàn bộ style inline sang lớp CSS sinh từ SCSS. Các giá trị lặp lại được gom thành biến và mixin.

original.html giữ bản gốc để so sánh. Chạy: npx sass 1515/scss/main.scss 1515/css/style.css --no-source-map
